# Audio-Inspired-Foundation-Models-for-Post-Merger-Gravitational-Wave-Anomaly-Screening

**Author:** Ruslan Alaskarov

This repository contains the official code, data generation scripts, and reproducibility notebooks for the preprint: 
*"Audio-Inspired Foundation Models for Post-Merger Gravitational-Wave Anomaly Screening: A Two-Stage Metric Learning Approach"*.

## Overview
Detecting high-frequency post-merger gravitational-wave transients is a major challenge due to non-stationary interferometer noise. This project introduces a two-stage anomaly-screening framework utilizing a frozen Audio Spectrogram Transformer (AST) and metric learning. 

The pipeline processes real LIGO Livingston (L1) background noise injected with synthetic phenomenological post-merger waveforms (damped sinusoids). It employs a dual-centroid Mahalanobis framework to explicitly disentangle out-of-distribution (OOD) pure detector noise from signal-like anomalous damping events (proxies for non-standard energy-loss channels).

## Repository Structure

* `src/`: Core Python modules.
  * `data_generator.py`: Phenomenological signal modeling, analytical PSD noise generation, and frequency-domain whitening.
  * `models.py`: The `AstroAST_Pipeline` architecture with the frozen `MIT/ast-finetuned-audioset` backbone and metric-learning heads.
  * `utils.py`: Helper functions, including strict random seed fixing for reproducibility.
* `notebooks/`: Jupyter notebooks used to generate the results and figures in the paper.
  * `01_baseline_mc_dropout.ipynb`: Evaluates the baseline 1D/2D CNNs and demonstrates the variance collapse in heteroscedastic NLL probabilistic regression.
  * `02_ast_metric_learning.ipynb`: Implements the AST feature extraction, latent space t-SNE projection, and the two-stage Mahalanobis evaluation.
* `figures/`: High-resolution PDF plots generated by the notebooks and featured in the manuscript.
* `requirements.txt`: Exact library dependencies for environment replication.
* `limitations.md`: A transparent discussion of the physical and computational limitations of this proof-of-concept study.
